# Evaluation summary outputs

Small aggregate CSVs produced by `notebooks/Hybrid_Summarisation_Clause_Classification.ipynb` (the integration pipeline). These are the source data behind the dissertation's results tables — included here as evidence, since they're small enough to check in directly.

- **`sbert_paragraph_eval_summary.csv`** → source of **Table 5.1-1** (hybrid summarisation SBERT precision/recall/F1 across all system variants)
- **`sbert_eval_hybrids_upgraded.csv`** → subset comparison across the three main hybrid variants (`hybrid_mmr_dyn`, `hybrid_strong`, `hybrid_blend`)
- **`baseline_extractive_summary_metrics.csv`** → extractive-baseline classification metrics (micro/macro P/R/F1) at full-document and summary level
- **`pseudo_gold_eval.csv`** → source of **Table 5.3-2** (Clause Coverage Score, Recall of Critical Clauses, compression ratio, n_docs=365)

## Not included

The full per-document raw outputs (`summaries_hybrid.csv`, `extractive_textrank.csv`, `abstractive_pegasus.csv`, `clauses_legalprobert.csv`, `summaries_with_clause_predictions.csv/.parquet`, and associated `.xlsx` exports) are not included here. They range from ~1MB to 102MB — one exceeds GitHub's 100MB file-size limit outright — and are per-document prediction dumps across all 510 contracts rather than material a reviewer would read. They can be regenerated by running the integration notebook against `CUAD_v1.json`.
